# Bhawanipur Global Campus recreation test — reference findings

Source: https://bhawanipurglobal.edu.in/

## Observed homepage structure

The public homepage is a long-form institutional landing page branded as **Bhawanipur Global Campus**, formerly NSHM Kolkata. It uses a dark maroon/plum navigation shell with warm coral-orange action buttons and a minimalist white/gray hero area. The primary navigation includes About, Programme, Admissions, Student Life, Faculty, Internship & Placement, and Beyond Academics. The top utility area exposes Apply Now, Enquire Now, media/contact links, a batch-launch announcement, and a phone number.

The hero prioritizes a large editorial space with an `EXPLORE PROGRAMME` CTA, followed by a diagonal white information band containing the BGES legacy statement and fixed Apply Now / Enquire Now actions. The content hierarchy continues through: About BGC, institutional metrics, Future of Learning, programme-category tabs, programme cards, placements and careers, recruiter logos, student outcomes/testimonials, faculty, and footer contact/navigation.

## Public image references observed in page HTML

The page exposes a logo SVG and public image URLs for the BGES logo, about/learning imagery, programme images, recruiter logos, and student/faculty assets. The recreation should use independently sourced or newly generated visual placeholders rather than republishing proprietary imagery or logos without permission.

## Recreation acceptance target

The test recreation should preserve the **information architecture, visual rhythm, palette, CTA hierarchy, editorial feel, angled section transitions, category filtering, responsive card layout, and institutional credibility cues** while using original copy adaptations and clearly marked placeholder/generated imagery. The implementation should be a functional single-page experience with responsive desktop/mobile behavior and interactive programme filtering.
