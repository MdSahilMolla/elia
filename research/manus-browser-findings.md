# Verified Manus capability notes

Source: https://manus.im/

The official homepage positions Manus as an action engine that executes tasks and lists web app, design, slides, games, browser operator, wide research, mail, and Slack integrations as product surfaces.

Source: https://manus.im/features/manus-browser-operator

The official Browser Operator page claims multi-step autonomous delegation across sites; operation inside the user’s active browser session and existing logins; access through the user’s local IP/network; form filling and cross-platform extraction; and user permission to grant browser access. It also explicitly exposes stop/oversight as a product concern in its FAQ and shows examples involving message drafting, job applications, and public posting.

Implication for Elia: browser control alone is not differentiation. Elia already has a browser bridge on the Manus branch, but autonomous execution currently needs stronger policy enforcement, durable evidence, resumability, and explicit action accountability so the agent can be trusted to run unattended.

Source: https://www.openhands.dev/

OpenHands publicly emphasizes autonomous end-to-end software work, dependency-aware orchestration across large/legacy codebases, parallel agents without conflicts, secure isolated execution, and full auditability.

Source: https://browser-use.com/

Browser Use publicly offers browser agents, managed browser infrastructure, task execution, data extraction, shopping/checkout, travel/booking, testing, research, and workflow templates. Browser control and browser infrastructure are therefore crowded capabilities.

Strategic conclusion: Elia should not compete on “can click websites” or “can run parallel coding workers.” Its defensible wedge should be a local-first autonomy control plane: every action is policy-evaluated, evidenced, reversible where possible, resumable after interruption, and learned from with measurable outcomes. The agent should be able to explain not only what it did, but why it was authorized, what evidence proves completion, what remains uncertain, and how to safely undo or replay the decision.
