Bhawanipur Global Campus — Homepage Recreation

This is a single-page, static recreation of the Bhawanipur Global (BGC) homepage for testing purposes. It preserves the information architecture, palette cues (maroon header, coral-orange CTAs), hero with angled transition, institutional metrics (with count‑up), Future of Learning, programme category filters with working JS, programme cards, placements/recruiters, student outcomes, faculty, and footer/contact. All images are newly generated placeholders.

Structure
- index.html — Semantic markup for all sections with anchors: #about, #metrics, #future, #programmes, #placements, #outcomes, #faculty, #contact
- styles.css — Mobile‑first responsive styles with CSS custom properties
- script.js — Nav toggle, counter animation, and programme filtering logic
- assets/* — SVG placeholders (hero, future, programme cards, recruiter logos, portraits)

Preview locally
1) Open a terminal from the project root
2) Run: python3 -m http.server 8000
3) Visit: http://localhost:8000/workspace/bhawanipur-recreation/

Notes
- Copy is adapted and generic; imagery is placeholder only and clearly marked.
- Programme filter categories: Business and Management, Pharmacy, Allied Health, Advanced Computing, Media, Design, Hospitality & Culinary Arts.
