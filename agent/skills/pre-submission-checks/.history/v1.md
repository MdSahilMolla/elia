# Pre-submission Checks

When editing TypeScript files in `src/tools`, always separate function parameters and object properties with commas to prevent TS1005 errors.

When authoring CSS, prefix class names with `rp-` (or similar project-specific prefix) to scope selectors and avoid global leakage, but keep specificity low enough to allow easy overrides—avoid ID selectors or long chains unless absolutely necessary.

Before invoking `submit_assumptions`, verify that every assumption has an associated verdict; do not proceed if any assumption lacks a verdict.

Before invoking `submit_acceptance`, confirm that all required game deliverables are present and that each acceptance criterion has an associated verdict.

Before executing imported Python modules, run `python3 -m py_compile <module>` to catch syntax errors early and prevent runtime hangs due to import timeouts.
