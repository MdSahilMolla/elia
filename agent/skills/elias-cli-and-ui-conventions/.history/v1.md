# Elia CLI and UI Conventions

## Command Execution
Use `run_command` for all script invocation, keeping interactions non-interactive. Do not pipe input to Python scripts using `echo -e`; instead use `printf` for reliable piped data.

## Python Safety
Before importing any package, install dependencies with `pip3`. Pre-compile modules with `python3 -m py_compile` to catch syntax errors early and avoid backend import timeouts.

## UI Styling
Implement a fixed top navigation bar using `position: fixed; top: 0;` with a subtle backdrop-filter to match the humanastudio.com aesthetic. Use a black/white palette with system-ui fonts. Include a marquee footer and pill-shaped buttons. Preserve these styles across pages.
