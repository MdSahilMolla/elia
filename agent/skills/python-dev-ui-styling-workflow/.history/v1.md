# Python Dependency and UI Styling Workflow

## Python Dependencies
Install packages with `pip3` before importing them. Pre-compile modules using `python3 -m py_compile` prior to execution to detect syntax errors and avoid runtime hangs.

## Navigation Bar
Implement fixed top navigation using `position:fixed; top:0;` with a subtle backdrop-filter to match the humanastudio.com aesthetic.
