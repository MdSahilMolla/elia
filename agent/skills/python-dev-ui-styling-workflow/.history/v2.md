# Python Development and UI Styling Workflow

## Environment & Command Workflow
- Run all Bun commands (`install`, `build`, `dev`, `test`) from the `workspace/flower-blooming` directory. Never run them from the repository root.
- Keep all command paths relative to the workspace root. Do not include absolute user paths.
- When invoking nested paths (e.g., `src/autonomy/loop.ts`), verify the file exists first. Use `grep` on the parent directory to list available files if unsure.
- When invoking `grep`, handle non‑zero exit codes gracefully (e.g., exit code 1 when no matches are found).
- Before checking TypeScript outputs with `node --check`, run `bun run build` in the appropriate workspace (`workspace/portfolio-demo`) so compilation artifacts and relative imports resolve.
- When invoking `npx skills add`, include the `-y` flag to auto‑approve and provide `--agent '*'` to satisfy required options.

## Python Safety
- Install packages with `pip3` before importing them.
- Pre‑compile modules using `python3 -m py_compile` prior to execution to detect syntax errors and avoid runtime hangs.
- Avoid executing commands that require interactive input (e.g., Python’s `input()`) via `run_command`; use only non‑interactive commands in this environment.
- Avoid using `echo -e` for piped input to Python scripts. Use `printf` instead.

## UI & Theme Design
- Start a research‑paper theme website with a static `index.html` and a single `styles.css`. No build tools or external dependencies are required.
- **Colors & Fonts:** Use a black/white palette with system‑UI fonts.
- **Layout:** Implement fixed top navigation using `position: fixed; top: 0;` with a subtle backdrop-filter. Include a marquee footer.
- **Components:** Use pill‑shaped buttons.
- **Style Quality:** Apply minimalism. Keep CSS concise, avoid redundant rules, and use subtle interactive states such as hover lift and shadow for phases and buttons.
